# AI 群聊（多模型讨论）

把不同的大模型拉进**同一个对话**，让它们围绕一个话题讨论、辩论、协作。
支持**私密@**：你 @ 某个模型的私密消息，其他模型看不到。
支持**多供应商**：不同 URL + 不同 Key 的模型可以混在一个群里。

## 能力

| 能力 | 说明 |
|---|---|
| 多供应商 | 可添加任意多个 OpenAI 兼容服务（URL + Key 各自独立），模型列表分别拉取 |
| 多成员群聊 | 每个成员 = 供应商 + 模型 + 人设提示词 + 独立温度 |
| 三种调度 | **手动 @** / **轮流** / **主持人**（由某个模型决定下一个谁说） |
| 私密 @ | 输入 `@@名字 内容`，只有你和该成员能看到；其他模型的上下文里没有这条 |
| 流式输出 | 边生成边显示，支持 `reasoning_content`（思考过程灰字显示） |
| 本地存储 | 配置与聊天记录在本地，每个供应商的 Key 单独加密（Windows DPAPI） |

## 运行

```powershell
cd D:\Harness\ai-group-chat
start.cmd        # 推荐：会清掉 ELECTRON_RUN_AS_NODE 环境变量
# 或
npm start
```

> 如果环境里有 `ELECTRON_RUN_AS_NODE=1`，Electron 会以纯 Node 模式运行并报
> `app.getPath` 错误。`start.cmd` 已处理这个坑。

## 首次配置

1. 左下 **⚙ 设置**
2. **+ 添加供应商** → 填名称、API 地址（如 `https://api.example.com/v1`，会自动补 `/v1`）、Key
3. 点该卡的 **拉取模型**（会先保存 Key 再请求）
4. 看到「共 N 个模型」后点 **保存**
5. 左侧点成员 → 选 **供应商** + **模型**，写人设

需要多个服务商就重复 2-4，每个供应商的 Key 独立保存。

## 三种调度模式

| 模式 | 行为 |
|---|---|
| 手动 @ | 发消息后按 @ 点名；不点名则所有成员依次回答 |
| 轮流 | 每个成员轮流回答，轮数可调 |
| 主持人 | 指定（或默认第一个）成员当主持，它输出 `{"next":"名字","prompt":"提示"}`，被点的人回答；轮数 = 总发言次数 |

## 输入语法

| 写法 | 效果 |
|---|---|
| `@评审员 这段代码有问题吗` | 公开点名，所有人都能看到 |
| `@@评审员 帮我看看这个密钥对不对` | **私密点名**，只有你和「评审员」能看到 |
| 直接输入内容 | 按当前调度模式处理 |

键盘：**Enter 发送**，**Shift+Enter 换行**；中文输入法选词时按 Enter 不会误发送。

## 私密消息是怎么隔离的

每条消息带 `visibility`（`public` / `private`）和 `privateTo`（成员 id 列表）。
给某个成员拼上下文时只放：

- 所有 `public` 消息
- `privateTo` 包含**该成员**的 `private` 消息

其他模型的请求体里**物理上不存在**这条私密内容。

注意：隔离的是**模型上下文**，不是端到端加密 —— 私密消息仍以明文存在本地 `chats.json`，
也仍会发送给该成员背后的模型服务商。

## 数据位置

```
%APPDATA%\ai-group-chat\config.json   # 供应商（URL + 加密 Key）、成员、设置
%APPDATA%\ai-group-chat\chats.json    # 聊天记录
```

菜单「文件 → 打开数据目录」可直达。

Key 存储格式：`dpapi:<base64>`（系统加密）或 `plain:<base64>`（系统加密不可用时的降级）。

## 旧配置迁移

从单供应商版本升级时，旧的 `baseUrl` / `apiKeyEnc` 会自动转成一个名为「默认」的供应商，
已有成员自动挂到它下面。升级前建议备份 `config.json`。

## 打包

### 安装版（推荐）

```powershell
npm run dist
```

产物：`release\AI群聊-安装程序-<版本>.exe`（NSIS 安装向导，可自选安装目录，自动创建桌面/开始菜单快捷方式）。

安装位置：`%LOCALAPPDATA%\Programs\ai-group-chat\`
卸载：设置 → 应用 → AI群聊，或运行安装目录下的 `Uninstall AI群聊.exe`。

### 免安装版

```powershell
npm run pack
```

产物：`dist\AI群聊-win32-x64\AI群聊.exe`，整个文件夹一起拷走即可。

### 数据目录

固定在 `%APPDATA%\ai-group-chat`，开发版、免安装版、安装版共用同一份配置；
卸载程序默认**不删除**这份数据。

## 消息操作

| 操作 | 说明 |
|---|---|
| 悬停消息 → **重新生成** | 删掉这条及其后，重新请求同一个成员 |
| 悬停消息 → **编辑** | 把该条文本放回输入框，清掉其后的记录，改完回车重发 |
| 悬停消息 → **删除以下** | 从这条（含）往后全部删除 |
| 生成中 → **停止** | 立即中断，保留已生成的部分，标记「已停止」 |

## Token 统计

每条回复下方显示 `↑输入 ↓输出 · 合计 tokens`，顶部显示本次会话累计。
用量来自服务端返回的 `usage`（请求时带了 `stream_options.include_usage`）；
不返回 usage 的服务商则显示为空。


## v0.3 新增

### 多会话（三栏布局）

```
[会话列表 200px] [成员 240px] [聊天区]
```

- 每个会话独立保存消息，自动落盘（`sessions/<id>.json` + `sessions.json` 索引）
- 新建 / 切换 / 双击重命名 / 悬停删除
- 会话标题自动取首条消息
- 旧版 `chats.json` 会自动迁移成「历史会话」

### 思考强度

成员设置里选 **关 / 低 / 中 / 高**，请求带 `reasoning_effort`；
服务端不认会自动去掉重试（记 `diagnostics.log`）。成员列表显示 `· 思考:高`。

### 本地知识库

设置 → 知识库 → 添加文件。

| 类型 | 处理 |
|---|---|
| PDF | pdf-parse 提取文本 |
| Word (.docx) | mammoth 提取 |
| TXT / MD / 代码 | 直接读 |
| 图片 | **会看图的成员**（成员里勾"支持看图"）直接附图；其他成员走 Windows 自带 OCR |

资料正文按预算拼进 system 提示；超出上限自动截断。预算可在设置里调（默认 12000 字符）。

### 联网搜索

顶部勾选「🌐 联网」：**每轮对话先搜一次，结果共享给所有成员**。

- 零成本抓取：Bing → DuckDuckGo 依次尝试
- 取前 8 条结果 + 抓前 3 个网页正文
- 聊天里显示"参考了哪些网页"
- 抓取失败会明确提示，不会假装搜过

### 诊断

按 `Ctrl+Shift+D` 输出焦点诊断到聊天，并写入 `%APPDATA%\ai-group-chat\diagnostics.log`。

## 已知限制（v0.3）

- 没有 token 统计与成本估算
- 没有对话分支 / 重新生成
- 主持人模式依赖模型输出合法 JSON，失败时退回轮流
- 代理是全局设置（系统代理或手动指定），不能按供应商区分
- 打包 exe 还没做（先用 `start.cmd`）
