# 智库 · 使用说明

把多个大模型拉进**同一个对话**，让它们讨论、辩论、协作。纯网页、无需安装、**不经过任何服务器**——所有请求直接从你的浏览器发给你自己填的 API。

## 界面

```
[会话列表] [成员] [聊天区]
```

- **会话**：每个会话独立保存，自动存本地，可新建 / 重命名 / 删除
- **成员**：每个成员 = 一个供应商 + 一个模型 + 一段人设 + 温度 + 思考强度
  - 成员是**按会话独立保存**的：**新建会话成员为空**，需要自己添加；各会话的成员互不影响
- **顶部**：调度模式（手动 @ / 轮流 / 主持人）、轮数、🌐 联网开关、导出 MD
- 两栏都可以点顶端的 `⟨` 收起

## 第一次使用

1. 点左下 **⚙ 设置**
2. **+ 添加供应商**：填名称、API 地址（OpenAI 兼容，如 `https://api.xxx.com/v1`）、Key
3. 点该卡的 **拉取模型**（会先保存 Key 再请求）
4. **保存**
5. 左侧点成员 → 选供应商 + 模型，写人设

## 输入语法

| 写法 | 效果 |
|---|---|
| `@名字 内容` | 公开点名，所有成员都能看到 |
| `@@名字 内容` | **私密点名**，只有你和该成员能看到 |
| 直接输入 | 按当前调度模式处理 |

键盘：**Enter 发送**，**Shift+Enter 换行**（中文输入法选词时不会误发）。

## Markdown 渲染

模型回复里的 Markdown 会自动渲染：标题、列表、表格、代码块、引用、链接都会正常显示。
所有 HTML 都经过 DOMPurify 过滤，模型输出里的脚本/事件属性不会被执行。

## 三种调度

| 模式 | 行为 |
|---|---|
| 手动 @ | 按 @ 点名；不点名则所有成员依次回答 |
| 轮流 | 每个成员轮流回答；**轮数填 0 = 不限，自由讨论**，直到你点「停止」 |
| 主持人 | 顶部下拉选择主持人，它输出 `{"next":"名字","prompt":"提示"}` 决定下一个发言者；认为讨论充分时可输出 `{"done":true}` 宣布结束 |

**关于轮数**

- `轮数 = N`（N ≥ 1）：轮流模式 = 整个群体轮 N 遍；主持人模式 = 主持人点名 N 次
- `轮数 = 0`：两种模式都变成**不限轮数**，一直进行到你点「停止」或主持人宣布结束
- 安全上限：不限轮数时默认最多连续 200 次发言，达到后**暂停并弹出「继续讨论」按钮**
  - 点一下就再给一轮额度继续跑，不会硬性终止
  - 上限数值可在「设置 → 安全上限」里改（默认 200）

## 知识库

设置 → 知识库 → **+ 添加文件**（可多选）或 **+ 添加文件夹**（仅桌面版）。

- **添加文件**：手动挑选，支持一次多选
- **添加文件夹**：递归扫描该目录下的 pdf / docx / txt / 代码文件（最多 800 个，自动跳过 node_modules、.git 等）
- **按会话隔离**：每个会话有独立的知识库，新建会话为空；切回旧会话恢复它自己的资料

| 类型 | 处理 |
|---|---|
| PDF | pdf.js 提取文本 |
| Word (.docx) | mammoth 提取文本 |
| TXT / MD / 代码 | 直接读取 |
| 图片 | 会看图的成员直接看图；其他成员用你指定的**视觉模型转写成文字** |

> 图片转写需要至少一个成员勾选了「支持看图」。没有的话图片会被跳过。

## 联网搜索

勾选顶部 **🌐 联网**，每轮对话开始前先搜一次，结果共享给所有成员。

实现方式：通过 `r.jina.ai`（免费网页转文本服务）抓取必应结果和网页正文。
**免费额度 20 次/分钟，多人共用同一份额度**，超限会提示"搜索不可用"，此时会退化为纯模型回答。

## 数据存在哪

全部存在**你自己浏览器的 IndexedDB** 里：

| 内容 | 位置 |
|---|---|
| 供应商 / 成员 / 设置 | `aigc-web` 数据库 → `kv` 表 |
| 会话消息 | `aigc-web` → `sessions` 表 |
| 知识库解析结果 | `aigc-web` → `kbcache` 表 |

- **不经过任何服务器**，别人看不到你的 Key 和聊天记录
- 换浏览器 / 清缓存 / 用无痕模式 → 数据会丢
- **不要在公共电脑上使用**

## 关于网页版的 Key 存储

网页版把供应商配置（含 Key）存在浏览器 IndexedDB 里：

- 存储形式是 **Base64 编码**，**不是加密**——能防止肉眼直接看到，但挡不住有浏览器权限的人
- Key 只发给**你自己填的那个 API 地址**，不经过任何中间服务器
- 清除方式：浏览器设置里清除该站点数据，或换一个浏览器配置文件
- 建议：只在 HTTPS 站点、自己的电脑上使用；公共电脑上用完请清除站点数据

## 常见问题

**Q：拉取模型时报"请求被浏览器拦截"？**
说明这个中转站不允许网页跨域访问（CORS）。换一个支持 CORS 的站，或用支持跨域的地址。

**Q：刷新后知识库文件失效了？**
文件本身不保存，只保存解析出来的文字。图片转写结果有缓存；如果提示失效，重新添加一次文件即可。

**Q：能多人同时用吗？**
可以。每个人打开同一个网址，各填各的 Key，数据互不干扰。

**Q：Key 安全吗？**
Key 只存在你自己浏览器本地，代码里没有任何上传逻辑。但页面是公开的，建议只在 HTTPS 下使用，且不要用来源不明的镜像站点。

## 按会话隔离的三样东西

| 内容 | 在哪改 | 新建会话时 | 切回旧会话 |
|---|---|---|---|
| 成员 | 中间栏「+ 添加」 | 空 | 恢复该会话成员 |
| 知识库 | 输入框旁「📚 知识库」 | 空 | 恢复该会话资料 |
| 群组提示词 | 成员栏「群组设定」 | 空 | 恢复该会话提示词 |

三样都只影响当前会话，互不干扰。

## 右键菜单

在输入框里右键可以剪切、复制、粘贴、全选；在聊天内容里选中文字后右键可以复制。
桌面版是系统原生菜单（粘贴等同 Ctrl+V），网页版是应用内菜单。

## 查看版本与数据位置

设置弹窗底部会显示当前版本、Electron 版本、更新地址，以及数据目录（一键打开）。

## 策划组队 + 议题卡审核

这是 v0.5.0 的主线功能：把一轮"人工组织的审核"变成"自动组队 + 逐卡推进"。

### 第一步：选策划模型

设置 → 策划模型 → 选一个供应商和模型。它只负责"设计审核方案"，不参与审核本身。

### 第二步：放资料

把要审的文档、代码放进当前会话的知识库。策划组队会读取这些文件（每份取头部，长文件再取尾部），弹窗里会显示「知识库：N 份文档（M 字）」。

### 第三步：生成方案

议题栏点「策划组队」→ 写需求 →「生成方案」。策划模型会输出：

- 需要几个 Agent、各自分工
- 每个 Agent 的完整提示词
- 每个 Agent 用哪个模型（只从你已配置的模型里选）
- 谁是主持人
- 拆出哪些议题卡

### 第四步：改到满意

在「修改意见」里写你的想法（例如"减少一个成员""增加安全复核"），点「按意见重新生成」。可以反复改。

### 第五步：确认并应用

点「确认并应用」才会真正创建成员和议题卡。不会自动覆盖。

### 第六步：逐卡审核

在输入框发一句话，主持人会按议题卡逐张推进：

- 每张卡讨论完，主持人判定「完成」并给出结论
- 结论写进卡片，卡片变绿（已审核）
- 自动进入下一张
- 中途可以「暂停」（当前这条说完停下）或「停止」

### 议题卡操作

| 操作 | 效果 |
|---|---|
| 点击卡片 | 收起 / 展开（收起后只显示状态和标题） |
| 点 ✎ | 编辑标题、审核要求、验收标准 |
| 「+ 添加」 | 手动新建一张卡 |
| 编辑里「删除」 | 删除这张卡 |

### 注意

- 首版只审核你提供的文字、代码、文件，**不会实际运行被测软件**
- 结论里会区分「有依据 / 推测 / 需执行验证 / 资料不足」，不把没验证的东西说成实测
- 想实际跑测试，交给 Harness 或 OpenClaw
